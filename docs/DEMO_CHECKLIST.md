# CodeOracle Demo & Screenshot Checklist

To properly showcase CodeOracle in a portfolio or presentation, capture screenshots or record a 90-second video following this sequence. Do not use AI-generated or fake screenshots; capture these directly from the running production application.

## Suggested Walkthrough Sequence

1. **Landing Page**: 
   - Capture the top hero section showing the unified aesthetic and the interactive 3D topology preview.
2. **Authentication**: 
   - Show the split-screen `/signin` or `/register` page highlighting the visual storytelling and accessible form validation.
3. **ZIP/GitHub Ingestion**: 
   - Show the repository composer modal actively polling during a GitHub ingestion or ZIP upload.
4. **Project Workspace (System Pulse)**: 
   - Capture the main workspace view showing the high-level metrics, health score, and technology breakdown.
5. **Risk Hotspots**: 
   - Display the complexity scatter plot or risk indicators showing files that need attention.
6. **Dependency Graph**: 
   - Capture the interactive node/edge graph demonstrating how modules are interconnected.
7. **Neural Map**: 
   - Take a screenshot of the 3D Neural Map (rendered via React Three Fiber) demonstrating spatial code topology.
8. **Generated Tests**: 
   - Show the UI rendering mock test generation for a specific AST-parsed function.
9. **Refactor Proposals**: 
   - Display a syntax-checked, unified diff of a refactoring suggestion.
10. **Migration Plan**: 
    - Highlight the modernization readiness scores and the calculated blast radius.
11. **Export JSON & Mermaid**: 
    - Show the downloaded artifacts (a raw JSON structure and a Mermaid markdown file).
12. **Production URL**: 
    - Ensure the browser address bar is visible in at least one screenshot, showing the live `https://codeoracle-l7ay.onrender.com` URL to prove production deployment.

## README Visuals
Once screenshots are captured, save them to a `docs/images/` directory and embed them within `README.md` using standard Markdown syntax.
