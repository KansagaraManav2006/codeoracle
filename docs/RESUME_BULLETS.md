# CodeOracle - Resume Bullets

- Architected and deployed a full-stack code analysis platform using React, TypeScript, Python, and FastAPI to automatically map and evaluate dependencies in legacy codebases.
- Engineered a custom Abstract Syntax Tree (AST) parsing pipeline in Python to extract structural metadata, reducing codebase discovery time by visualizing complex inter-module dependencies.
- Implemented a resilient asynchronous polling system in React and FastAPI to handle long-running GitHub ingestion and analysis tasks, maintaining UI responsiveness without HTTP timeouts.
- Configured a multi-stage Docker build integrating Vite production assets with a FastAPI web server, utilizing strict `Cache-Control` strategies to eliminate dynamic-import errors during deployments.
- Developed secure session management using HTTP-only cookies and bcrypt, integrated Google OAuth2, and enforced strict row-level project isolation in PostgreSQL via SQLAlchemy.
- Authored a comprehensive backend test suite with 160 isolated Pytest scenarios, ensuring 100% data integrity across complex ORM transactions and API workflows.
